# FX Operations Automation & Monitoring

An FX operations automation and monitoring system built with n8n, Python, JavaScript, REST APIs, PostgreSQL, and Docker.

## Overview

The system is designed to ingest FX market data from external APIs, validate and normalize structured data, store it in a relational database, and monitor operational workflows for anomalies and failures.

## Tech Stack

- n8n
- Python
- JavaScript
- REST APIs
- PostgreSQL
- Docker

## Development Roadmap

- Automated FX market data ingestion
- Data validation and normalization
- PostgreSQL persistence
- Operational checks and anomaly detection
- Workflow health monitoring
- Error handling and alerting
- AI/LLM-generated incident summaries
